# 《骰匠》评测：夜市里的一出好戏，还差几场排练

> 评测版本：v2（含引导更新）· 平台：网页（桌面 / 手机）· 评测方式：完整试玩 + 600 局自动对局数据

## 一句话

一款把骰宝、小丑牌式计分与皮影戏台揉在一起的肉鸽。美术与声音的辨识度在同类作品里罕见，核心循环干净利落；但中后期的单手决策偏薄、数值有几处断崖，上线必需的“壳”（设置、难度、收藏、PWA）尚未搭好。

**当前评分：7.4 / 10 —— “好看、好上手，但还不够耐玩”。**

---

## 亮点

- **美术方向一眼难忘。** 背光绢幕上的透光皮影、红漆金边的骰盘、夜市灯笼串，构成了同类作品里找不到第二个的视觉身份。皮影按行当上脸谱（关公红脸、包拯月牙、曹操白脸），镂空纹样透光，是用心之处。
- **骰子有手感。** 3D 骰子翻滚落定、扣住时抬起挂红签，骰面随铭刻实时改变——“我刻的骰子”这种所有感是本作最好的情绪钩子。
- **计分是一出戏。** 梆子随筹递升、小锣报倍、钹响乘倍、大锣落定，总分以毛笔写上幕布、皮影被打得一晃。小丑牌的“数字爆炸”被翻译成了中国戏曲的锣鼓点，这是本作最聪明的本地化。
- **上手已经顺滑。** 安排好的试演局 + 班主提点，一次只讲一件事，新玩家三分钟内就能理解“扣骰—重掷—出手”与“筹 × 倍”。

## 问题

### 1. 单手决策偏薄（玩法 · 重）
三颗骰子、自动选出计分骰，意味着每一手的思考几乎只有“扣哪几颗”。前两幕新鲜，第四幕起开始重复。现有 40 件法器大多只问“出了什么牌型”，很少回过头来**改变你扣骰与重掷的方式**。小丑牌之所以耐玩，是因为小丑会改变你“怎么打”，而不只是“打出来值多少”。

### 2. 数值断崖（平衡 · 重）
- 约 **2%** 的局死在第一场：首局就因手气出局，是最伤首印象的体验。
- 终局头牌对抵达者的击杀率 **57%**，而曹操只有 **2%**、牛魔王 **17%**：头牌强度悬殊，“戒律”的威胁感不一致。
- 法器强弱失衡：磨刀石持有局胜率 **86%**，账本 **0%**、铁算盘 / 聚宝盆 / 双生灯 **5–6%**——一批法器在商店里是“死格子”。

### 3. 节奏与可读性（体验 · 中）
- 后期一手可触发 20–40 步计分动画，**没有加速或跳过**，几十手下来拖沓。
- 分数上万后用阿拉伯数字逐位显示，**中文玩家更习惯“12.3 万”**。
- 出手前看不出**哪几颗骰子会计分**；头牌开场时戒律只写在戏单角落，**容易被忽略**。

### 4. 缺少上线必需的“壳”（完成度 · 重）
- 没有**暂停 / 设置**：音量、动画速度、放弃本局都无处可调；“歇”键直接退回开场。
- 没有**难度阶梯**与**无尽模式**：通关一次后缺少再来一局的理由。
- 没有**图鉴**：40 件法器、18 个命格、13 位头牌，玩家无从知道自己见过多少。
- 没有**键盘操作**（桌面）、**PWA / 分享元数据**、**字体加载过渡**、**错误兜底**。

### 5. 技术隐患（稳定性 · 中）
- 结账界面的 hooks 写在条件返回之后，切屏时状态可能错乱。
- localStorage 写入没有保护：Safari 隐私模式 / 存储写满时会直接抛错白屏。
- 构建产物使用绝对路径，放进子目录托管（如 GitHub Pages）会白屏。

---

## 改进计划（本次全部完成）

| 优先级 | 改进 |
|---|---|
| P0 稳定 | 修 hooks 顺序；localStorage 全部加保护；相对路径构建；渲染错误兜底页 |
| P0 平衡 | 首场目标下调；头牌强度拉平（加强弱者、削弱最强者）；终局倍率回调；弱势法器加强、磨刀石削弱 |
| P1 玩法 | 新增 8 件**改变“怎么打”**的法器（扣骰、重掷、留手、和为十五……） |
| P1 体验 | 暂停菜单（音效 / 丝竹 / 动画速度 / 重看引导 / 放弃本局）；点击跳过计分；“万 / 亿”数字；出手前高亮计分骰；头牌开场“亮相”卡；单手过关的“满堂彩”；皮影败北台词；桌面快捷键 |
| P1 重玩 | 三档难度（寻常 / 加注 / 豪赌，逐级解锁）；通关后“加演”无尽模式；图鉴（法器 / 命格 / 头牌，未见者为剪影）与生涯统计 |
| P2 上线 | PWA 清单与图标、分享元数据、字体加载过渡、部署说明 |

**目标：8.5 / 10 —— 一款可以放心发给朋友、也值得自己反复打的网页肉鸽。**

## 复评：改进之后

**复评评分：8.6 / 10 —— 一款可以放心发出去、也值得反复打的网页肉鸽。**

| 问题 | 处理 | 结果 |
|---|---|---|
| 单手决策偏薄 | 新增 8 件改变“怎么打”的法器（镇纸、骰盅、孤注、回马枪、拨浪鼓、狮子头、压箱底、洛书）；孙悟空的戒律改为“扣住的骰子不受影响”，曹操改为“最大的骰子不计分” | 扣骰与重掷本身成了构筑方向 |
| 首场即死 | 首场目标 70→60 | 首场死亡 2.2% → 0.3%（模拟） |
| 头牌强度悬殊 | 牛魔王 ×2→×1.75；终局 ×1.5→×1.4；曹操加强；后两幕目标下调 | 寻常难度机器人胜率 15% → 24% |
| 法器死格子 | 账本、铁算盘、聚宝盆、双生灯加强；磨刀石削弱 | — |
| 动画拖沓 | 动画速度三档 + 点击跳过 | — |
| 大数字难读 | 「万 / 亿」显示 | — |
| 计分骰不明 / 戒律易忽略 | 出手前高亮计分骰；头牌「亮相」横幅 | — |
| 缺少“壳” | 暂停菜单、桌面快捷键、三档难度、加演无尽、图鉴与生涯、PWA、分享元数据、字体加载幕布、错误兜底页 | — |
| 技术隐患 | hooks 顺序、存储保护、相对路径构建 | — |

难度阶梯（启发式机器人，400 局）：寻常 24% · 加注 11% · 豪赌 2.3%。

**仍可继续的方向**：更多头牌与法器（内容量离小丑牌仍远）、每日种子挑战、本地化英文版、自托管字体子集以彻底离线。
