# DRAGON TURF · 龍門之爭 — Chinatown Gang War

A top-down open-world crime sandbox set in a neon Chinatown. You are **Kai Lin**, back on Dragon Street after five years abroad, working for your uncle's fading crew (the **Jade Serpents**) against three rivals — the **Red Dragons**, **Black Lotus** and **Iron Tigers**. Steal cars, shoot your way out, run contraband between districts, take turf block by block.

Everything — the city, the art, the sound and the radio music — is generated by code at runtime. No image or audio files.

## Play

**Dev (native ES modules, no build):**

```bash
cd dragon-turf
python3 tools/serve.py 8780      # or: npm run dev   (no-cache server, so edits always reload)
# open http://localhost:8780/            (title screen)
#      http://localhost:8780/?play       (skip straight into the game)
```

**Single-file build (opens straight from disk):**

```bash
npm install
npm run build                   # -> dist/dragon-turf.html (~330 KB)
npm run check                   # headless sanity check: every mission target resolves, every turf has a hideout, races are reachable
```

## Controls

| Key | Action |
| --- | --- |
| `W A S D` | move on foot · gas / brake / steer in a vehicle |
| `Mouse` · `LMB` | aim · shoot / punch |
| `RMB` / `V` | melee swing (cleaver if you own it) |
| `G` | throw grenade / molotov |
| `Shift` · `Space` | sprint · dodge-roll (handbrake in a car) |
| `1`–`6` · `Q` · wheel | switch weapon |
| `E` | enter / carjack / hotwire / talk / shop / raid hideout |
| `H` · `T` · `C` · `Z` | horn · radio station · camera · zoom |
| `N` | taxi shift (while driving a taxi) |
| `Tab` / `M` | PDA: turf map, jobs, crew, market, stats |
| `Esc` / `P` | pause |
| `R` | retry a mission right after failing it |

## What's in it

- **A real city.** A procedurally generated island with six districts (Dragon Gate, Harbor Row, Old Quarter, Neon Heights, Smokestack Yards, Jade Hill), BSP-carved streets, ~120 buildings in a dozen archetypes (shophouses, tenements, temples, night-market stalls, container yards, towers…), parks, piers and boats, a day/night cycle, rain and thunder.
- **Turf war.** 14 named turfs owned by four crews. Raid a hideout (3 waves) to take it; owned turf pays every game hour into your safehouse stash. Rivals raid *your* turf and will take it if you don't show up. The other crews also fight each other on the map.
- **Cops that escalate.** Crimes only count if a cop (or a witness who phones it in) sees them. 1★ patrol cars → 2★ more guns → 3★ roadblocks → 4★ helicopter with a searchlight + SWAT → 5★ armoured Enforcer. Break line of sight to cool off, or use a Pay 'n' Spray.
- **Story missions.** Eight scripted jobs from Uncle Wei and Madam Lin with comic-panel cutscenes: a hotwire tutorial, protection rounds, a fireworks heist, a hit, a street race and a final assault on Brother Hu.
- **High freedom.** Contraband trading with moving prices and market news, taxi fares, chop-shop car exports, ambient muggings and gang skirmishes, drive-bys if you linger in hostile turf, destructible street furniture, explosive barrels, a weapon locker from fists to rifles and molotovs.
- **Procedural audio.** Synth engine with gear shifts, spatial gunfire, sirens, thunder, firecrackers and gongs in Chinatown, and a generative pentatonic radio (guzheng / erhu lo-fi and a synthwave station).

## Source layout

```
index.html              dev entry (loads src/main.js as an ES module)
build.mjs               esbuild bundle → dist/dragon-turf.html
tools/viewer.html       fly-camera world viewer (rendering without gameplay)
src/
├── main.js             bootstrap + frame loop
├── game.js             composition root: wires systems, run loop, save/load, death/arrest
├── config.js           global tunables
├── core/               math · rng · noise · color · events (bus) · input · save
├── data/               pure data: factions, weapons, vehicles, goods, missions, dialogues
├── world/              generation pipeline + queries
│   ├── layout.js       coast, districts, BSP street carving, piers
│   ├── blocks.js       block interiors (lots, markets, parks, temples, containers)
│   ├── buildings.js    building records · archetypes.js · districts.js
│   ├── scatter.js      lamps, lantern lines, paifang gates, clutter, boats
│   ├── roadnet.js      road graph (nodes/edges) + shortest path
│   ├── turfs.js · pois.js   turf map, hideouts, shops, contacts, safehouse
│   ├── world.js        tile grids, collision, raycast · clock.js  time of day
├── render/             all drawing
│   ├── renderer.js     frame composition (water → ground → sorted world → lights → grade)
│   ├── ground.js       baked ground chunks (roads, paving, markings, shadows, decals)
│   ├── buildingSprites.js · artkit.js · propSprites.js   cached building art & props
│   ├── pedSprites.js · vehicleSprites.js                 cached character / car sprites
│   ├── lighting.js     half-res light map for neon night · water.js · camera.js
├── entities/           ped · vehicle · projectile · pickup · heli · manager (spatial hash)
├── systems/            gameplay, each one owns a slice of state
│   ├── combat · vehicles · traffic · population · props · pickups · fx · weather
│   ├── wanted · turf · trade · economy · interact · playerControl · nav (flow fields)
│   ├── sidejobs · events (ambient street events)
│   ├── ai/             civBrain · gangBrain · copBrain · engage · steering
│   └── missions/       index (runner) · steps (step library) · resolve (position specs)
├── ui/                 hud · minimap · worldOverlay · comic (cutscenes) · portraits · screens/*
└── audio/              engine (spatial sfx, engine, siren, ambience) · music (generative radio)
```

Systems talk through `game.*` references and the `game.events` bus (`pedDied`, `noise`, `explosion`, `carjack`, `turfWon`…), so the police, turf, mission and population systems stay decoupled.
