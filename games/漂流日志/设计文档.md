# 《漂流日志 · Drift Log》游戏设计文档

> 参考作品：**Survival Log**（Midnight Workshop 开发 / Lilith Games 发行，Steam，2026-08-12 正式发售，单人，Windows）
> 本文分两部分：**一、对 Survival Log 的拆解**（美术 + 玩法）；**二、《漂流日志》的完整设计**（保留骨架、换主题、加入自己的巧思）。
> 同目录下的 `index.html` 是可以直接玩的原型，实现了第二部分的核心循环。

## 一、Survival Log 拆解

### 1.1 一句话概括
“你死过一次，看见了未来：离丧尸爆发还有 10 小时。”——**限时囤货（Hoard）+ 据点经营（Stronghold）+ 死亡轮回（Loop）** 的生存模拟。

### 1.2 核心循环（两段式）

| 阶段 | 玩家在做什么 | 核心张力 |
|---|---|---|
| **① 10 小时囤货期** | 在城市里跑超市、五金店、农贸市场；花钱买物资、扛回公寓；买家具/电器/建材装进家里 | **钱 × 时间 × 体力（负重）** 三项预算互相挤压 |
| **② 爆发后据点期** | 多层公寓据点：种菜、做饭、发电（柴油 / 手摇 / 太阳能）、管理饱食/士气/体力/生命；抵御丧尸围城、天气灾害（暴雨、寒潮、停电）；外出探索学校、废墟；无人机交易、营救邻居 | **长期资源分配**：每一瓦电、每一口粮 |
| **③ 死亡 → 轮回** | 带着“日志记忆”重来（Loop 计数、规划卡 Planning Cards、角色解锁） | **失败即经验**，下一轮路线更优 |

其他已确认要素：
- **三种开局身份**：工人 / 大学生 / 仓库管理员，开局资源和难度曲线不同。
- **Loot Spotter（囤货清单）**：实时显示已有物资和缺口，把“我该买什么”变成可视化 checklist。
- **家具插槽系统**：家里有小/中/大/壁挂/桌面/床/门/窗等槽位和总容量（截图：`Small 8/36、Medium 10/31、Door 2/1…`）。电器有功率（微波炉 30W）、安装时间（1m40s）、烹饪参数。
- **多结局**、115 个成就，补丁中加入了规划卡。
- **[Wish] 愿望系统**：角色会随机想要某种食物（“鸭肉卷 / 棉花糖 / 可乐 三选一”，带倒计时），满足后加士气。这是很聪明的小设计——把士气从一个数字变成一个“小任务”。

### 1.3 美术分析（基于 Steam 官方截图）

**镜头与空间**
- **3D 等距俯视（约 45–55° 俯角）、切掉屋顶的“玩具屋”视角**。墙体半高切开，玩家像看娃娃屋一样看到每个房间的全部陈设。这是“囤积类”游戏的关键——**囤积的满足感必须被看见**：货架上一排排罐头、水桶、药箱都是独立模型。
- 多楼层用右侧楼层切换（2F / Home / B1），一次只渲染一层。

**色彩与光照**
- 写实偏暖的 PBR 材质，**低饱和灰褐色基调 + 暖色点光源**（台灯、串灯、壁灯）。末日不是黑暗，而是“温暖的小窝 vs 冰冷的外部”。
- 夜晚外景偏冷蓝绿，室内橙黄，形成强烈的**安全感对比**。
- 功能性高亮用饱和色：种植箱的粉紫色补光灯、火焰、红色警报。

**UI 风格**
- **深色半透明面板 + 圆角 + 无衬线字体**，信息密度高但层级清晰，类似现代模拟经营（像 Frostpunk / This War of Mine 的“管理面板”气质，但更干净）。
- 颜色语义非常统一：
  - **金黄**：金钱（`$ 808`）、标题强调、“Complete Preparations”按钮
  - **绿色**：购买 / 确认 / 正向数值条
  - **红色**：负重超标（Encumbered）、门的耐久、围城警报
  - **青蓝色**：数字时钟（`17:20`）
- **顶部中央沙漏 + 倒计时**（`⌛ 08:55`）是第一阶段最重要的 HUD，永远在视线中央。
- **右上角 24 小时表盘 + 大号 DAY7 + Loop 计数**：时间与轮回是游戏的两条主轴，放在最显眼位置。
- **右下角四条状态条**：饱食（Satiety）/ 士气（Morale）/ 体力（Stamina）/ 生命（Life），图标 + 数值。
- **底部中央时间控制**（▶ ▶▶ ▶▶▶ ⏸）——经营游戏标配。
- **背包是“网格 + 重量”双限制**（类似塔科夫的 1x1 / 2x2 / 3x3 格子），物品是精致的 3D 渲染图标。
- 世界内悬浮标签：作物名 + 绿色倒计时条（`2D 00:31`），信息直接贴在物体上。

**角色**
- 普通人比例的写实角色（白 T 恤短裤的女生、连帽衫男生），强调“普通人”而非英雄，增加代入感。

**宣传图（Key Art）**
- 连帽衫背影站在堆满罐头、水桶、纸箱的仓库里，窗外是灰色城市。核心卖点一目了然：**囤货 = 安全感**。

### 1.4 它为什么好玩（设计结论）
1. **预知未来的“爽”**：别人还在正常生活，只有你知道要出事——“抢购”本身就有剧情张力。
2. **两段式让“准备”有回报**：第一阶段的每个决策都在第二阶段被检验，失败时玩家清楚知道“我上次少买了柴油”。
3. **轮回把挫败转化为知识**：Roguelite 的元进度和“玩家自身的知识”同时成长。
4. **可视化囤积**：东西摆满货架的视觉满足感，是这个品类的灵魂。

## 二、《漂流日志 · Drift Log》设计

### 2.1 高概念
> **你溺死过一次。睁开眼，是大潮来临前的 10 小时——今晚之后，整座港城会沉进海里。**
> 在城市被淹没之前，买齐物资、亲手造好你的木筏；之后，在一片汪洋上漂流、捕鱼、净水、抵御风暴和“黑潮”里的东西，找到传说中的“方舟”。

- 类型：限时囤货 + 移动据点经营 + 轮回 Roguelite
- 与原作的关系：**骨架相同（两段式 + 轮回 + 身份 + 状态四条 + 电力预算 + 围攻防御）**，但每个系统都换成“海”的逻辑，并加入下面 6 个原创机制。

### 2.2 六个“巧思”（与原作的关键差异）

#### ① 浮力即容量：囤得越多，沉得越低
原作的“家具槽位 + 背包负重”在海上变成一个更直觉的物理量：**木筏浮力**。
- 每块甲板提供浮力，所有物资和设施都有重量。
- 载重 < 70%：正常；70–100%：**吃水深**，浪会冲上甲板，随机打湿/冲走边缘物资；> 100%：**持续进水**，船体耐久下降。
- 结果：**囤货的贪婪与生存直接冲突**。原作是“背包放不下”，这里是“东西太多会把你自己淹死”。玩家必须决定：多带 20 升淡水，还是多一块甲板？

#### ② 潮汐时钟：城市在你脚下一点点沉没
原作的 10 小时城市是静态的。我们的城市会**按小时逐区淹没**：
- 第 3 小时：海滨市场进水关闭；第 5 小时：渔具店；第 7 小时：五金店……只有高地上的区域能撑到最后。
- 地图上每个区域显示“淹没倒计时”，**路线规划**变成第一阶段的核心解谜：先去低处抢货，再往高处走。
- 越晚，部分商店**涨价**（恐慌抢购）——这是原作“预知未来”的延伸：你知道，所以你可以提前买。

#### ③ 漂流瓶日志：写给下一个自己的信（轮回系统）
原作的“日志记忆 / 规划卡”在这里被具象化成**漂流瓶**：
- 每次死亡，你在船日志上写下一句话（从本轮“学到的经验”中选择一张卡），封进瓶子扔进海里。
- 下一轮开局时，这些瓶子会**冲上岸边**，成为永久被动加成（例如“船厂老板今早 8 点前打 7 折”“记得：黑潮在第 3 夜最凶”）。
- 每轮只能写**一封**，最多保留 5 封，旧的可以替换——**轮回成长是“选择性记忆”**，而不是无脑叠数值。
- 主题贴合：**游戏标题“日志”就是这些信**。

#### ④ 移动的据点：海图与洋流
原作的据点是固定的公寓，“探索”是离家出门。我们的据点**本身在漂**：
- 每天早上打开海图，从 2–3 个可达节点中选下一站：**楼顶废墟、漂浮集装箱、灯塔、幸存者筏、渔场**。洋流决定哪些点可达，**帆**和**桨**能修正方向。
- 每个节点是一次风险 / 收益选择（集装箱有好东西但可能引来黑潮兽，灯塔可以躲风暴）。
- 终点是传说中的**“方舟”**（第 14 天起出现在海图上）——给生存一个明确的方向感，而不是“活多久算多久”。

#### ⑤ 淡水是第二种“电”
原作的预算核心是电力。海上我们引入**淡水**作为与电同级的预算：
- **四条状态**改为：**饱食 / 水分 / 体力 / 士气** + 生命（水分取代了原作的“生命以外的第四条”，成为最急迫的指标）。
- 淡水来源：囤货（瓶装水，很重）、**雨水收集器**（看天气）、**太阳能蒸馏器**（看日照，慢）、**电动净水机**（耗电，快）。
- 电力来源：**太阳能板 / 风力机（海上独有，风暴时发电最多但可能被吹坏）/ 脚踏发电（耗体力）/ 柴油机（耗燃料）**。
- 这让天气有了“双刃剑”：**暴风雨**会损坏船体和太阳能，但同时是风电和雨水的丰收时刻。

#### ⑥ 系缆船队：横向扩张
原作“营救邻居、加楼层”；我们是**把救下的幸存者的小筏用缆绳绑在一起**：
- 每个幸存者带来一个小筏（额外浮力 + 一项技能：厨师 / 渔夫 / 机械师）。
- 缆绳在风暴中可能断裂——船队越大越强，但越难管理。
- （原型中以“救援幸存者 → 获得船员加成”的形式实现。）

### 2.3 第一阶段：沉城十小时（囤货期）

- **时间（v2 修订：行动制）**：08:00 → 18:00 共 10 小时，**只在行动时流逝**，不会真的倒计时——玩家可以慢慢思考。
  - 走路：按距离 15–60 分钟（骑手 -40%，超重 +50%）
  - 结账：5 分钟 + 每件 1 分钟（购物车 + 一次结账，不是每件单独扣时间）
  - 码头卸货：10 分钟；在码头组装设施：10–35 分钟（码头工减半）
- **资源**：现金（按身份 $650–$850）、时间、背包负重（12 kg，超重走路变慢，最多超载 50%）。
- **运输难题的解法**：五金店卖**手推车**（背包 +14kg）；船厂 / 五金店 / 超市可**送货到码头**（+$30，14:00 前，之后司机都跑了）——用钱换时间。
- **恐慌涨价**：12:00 之后每小时物价 +8%。
- **地图节点**（按海拔从低到高）：

| 区域 | 海拔 | 淹没时间 | 卖什么 |
|---|---|---|---|
| 海滨集市 | 1 | 第 3 小时 | 鲜鱼、蔬果、种子 |
| 渔具店 | 2 | 第 5 小时 | 渔网、鱼竿、鱼叉、浮标 |
| 船厂 | 2 | 第 6 小时 | 甲板木板、桶浮、帆、缆绳 |
| 五金店 | 3 | 第 7 小时 | 木材、钉子、太阳能板、工具 |
| 超市 | 4 | 第 9 小时 | 罐头、饼干、瓶装水、调料 |
| 药房 | 4 | 第 9 小时 | 急救包、抗生素、维生素 |
| 加油站 | 5 | 不淹 | 柴油、电池 |
| 码头（你的木筏） | — | — | 卸货、**在大潮前组装木筏**（耗时） |

- **囤货清单（致敬 Loot Spotter）**：实时显示 食物 / 淡水 / 建材 / 能源 / 医疗 五类是否达标。
- 背包满了必须回码头卸货（往返耗时）——**路线规划**是核心。
- **码头视图**：港口场景里直接看到你的木筏，可以在大潮前就把设施组装好（对标原作“爆发前布置家具”）。时间花在组装上，就不能花在采购上。
- 点击“启航”或时间到 18:00 → 大潮来临，进入第二阶段（若不在码头，背包物资丢一半）。

### 2.4 第二阶段：漂流（据点经营期）

**木筏**：网格甲板（初始 3×3，可扩展到 7×7），在甲板格上放置设施：

| 设施 | 作用 | 耗电 | 材料 |
|---|---|---|---|
| 储物箱 | +容量，防止物资被浪冲走 | — | 木材 |
| 雨水收集器 | 下雨时产淡水 | — | 木材+布 |
| 太阳能蒸馏器 | 晴天缓慢产淡水 | — | 木材+玻璃 |
| 电动净水机 | 快速产淡水 | 40W | 零件 |
| 渔网 | 被动产鱼 | — | 绳+网 |
| 种植箱 | 种菜（需淡水） | — | 木材+种子 |
| 炉子 | 烹饪（生鱼→烤鱼，士气+） | — | 金属 |
| 太阳能板 | 白天发电 | +60W | 面板 |
| 风力机 | 有风发电，风暴最强 | +40~120W | 零件+帆布 |
| 脚踏发电机 | 手动发电，耗体力 | +50W | 零件 |
| 防护栏 | 降低黑潮兽对边缘的伤害 | — | 木材+钉子 |
| 鱼叉炮 | 夜间自动攻击黑潮兽 | 20W | 金属+零件 |
| 灯 | 夜间士气+，吸引鱼也吸引怪 | 10W | 电池 |

**状态**：饱食、水分、体力、士气、生命；以及 **船体耐久** 和 **载重%**。

**天气**：晴 / 多云 / 雨 / 暴风雨 / 浓雾（雾天看不见海图上的危险）。

**威胁**：
- **黑潮兽群（替代丧尸围城）**：被污染海水催生的“沉没者”——触手、甲壳、发光的眼睛。夜间从水下啃食木筏边缘甲板；防护栏会先被啃，并让相邻甲板受伤 -60%；鱼叉炮自动射击；玩家可以点击黑潮兽用鱼叉刺。第 3、6、9、12 夜为“大潮夜”，规模最大（类似原作的围城事件 “Zombie Siege!”）。
- **风暴**：船体伤害 + 可能吹坏太阳能板 / 风力机。
- **淡水危机、腐败**：每条生鱼单独计时，放 24 小时就臭，必须及时烹饪。

**时间控制（v2）**：漂流阶段是可暂停的实时模拟（▶ / ▶▶ / ▶▶▶），开局默认暂停；**暴风雨、黑潮来袭、抵达目的地、清晨规划航线时自动暂停**，不会因为没盯着屏幕而突然死掉。

**愿望系统（致敬 [Wish]）**：角色偶尔想要“热汤 / 烤鱼 / 罐头桃子”，限时满足 → 士气大幅提升。

### 2.5 身份（开局三选一）
| 身份 | 优势 | 劣势 |
|---|---|---|
| **码头工** | 背包 +6 kg，建造速度 +50% | 现金少（$700） |
| **潜水教练** | 溺水不会立即死亡（生命 0 时一次复苏），探索收益 +30% | 现金中（$850） |
| **外卖骑手** | 区域间移动时间 -40%，开局自带 1 块电动车电池 | 现金最少（$650） |

### 2.6 轮回与漂流瓶卡池（节选）
| 漂流瓶 | 效果 |
|---|---|
| “船厂早上打折” | 第一阶段船厂所有商品 -30% |
| “我记得涨潮的时间” | 所有区域晚 1 小时被淹 |
| “多存点钱” | 开局现金 +$250 |
| “别贪” | 木筏初始浮力 +20% |
| “黑潮怕光” | 灯对黑潮兽造成伤害 |
| “雨会来的” | 雨水收集器产量 ×2 |
| “我学会了钓鱼” | 渔网产量 +50% |
| “风暴前加固” | 风暴船体伤害 -40% |

### 2.7 结局
- **方舟结局**：第 12 天起方舟出现在海图上，抵达即获救。
- **灯塔守望者结局**（隐藏，正式版）：在灯塔节点停留并修好灯（需电力 ≥ 200W）。
- **沉没结局**：死亡 → 写漂流瓶 → 轮回。

### 2.8 美术方向（对标原作，换成海）

| 维度 | Survival Log | 漂流日志 |
|---|---|---|
| 视角 | 3D 等距、切顶玩具屋 | 3D 等距、**无墙的开放木筏**，海面占画面 70% |
| 基调 | 灰褐色城市 + 暖色室内灯 | **深青色海面 + 暖色马灯**；“一盏灯 vs 一整片黑海” |
| 安全感符号 | 堆满的货架 | **堆满的木筏**（桶、渔网、晾晒的鱼干、绳结） |
| 危险色 | 红色警报、火光 | **荧光青绿的黑潮**（生物发光），与暖橙形成互补色 |
| UI | 深色半透明面板，金/绿/红/青语义 | **完全沿用**这套语义，加一个**蓝色 = 淡水** |
| HUD | 顶部沙漏倒计时；右上表盘 + DAY + Loop | 顶部**潮位计**（倒计时 + 水位线）；右上表盘 + DAY + Loop |

### 2.9 原型实现范围（`index.html`）
可玩的浏览器原型，覆盖上面的核心循环（玩法：双击 `index.html` 或在本目录运行 `python3 -m http.server` 后打开；漂流阶段 空格=暂停、1/2/3=倍速、B=建造、点击黑潮兽=鱼叉刺击）：
- 标题 → 身份选择（3 种）→ 漂流瓶记忆（读档）
- 第一阶段：行动制时间；2.5D 城市地图（光影随时间变化、逐区淹没）；购物车 + 结账 + 送货；手推车；码头港口视图里组装木筏；囤货清单
- 第二阶段：原木捆扎的等距木筏 + 昼夜光照 / 浪花 / 云影 / 灯光倒影 / 夜光浮游生物；17 种设施（均有独立造型）；角色走到设施前执行动作、夜里睡觉；海图目的地以地标形式出现在海面（楼顶、集装箱、灯塔、方舟…）；黑潮兽夜袭；愿望系统；危险自动暂停
- 死亡 → 选择漂流瓶写给下一轮（localStorage 永久保存）→ Loop+1
- 胜利：第 12 天起抵达方舟

### 2.10 后续（正式版）开发建议
1. **引擎**：Unity（URP）或 Godot 4；等距相机 + 甲板网格建造系统，模型风格参考原作的写实偏暖 PBR。
2. **优先验证**：浮力系统是否“好懂又有张力”——这是本作最大的差异点，应该第一个做出 3D 原型并测试。
3. **内容量**：50+ 物品、20+ 设施、8 种海图节点、4 类黑潮兽、3 个结局、20+ 漂流瓶。
4. **风险**：海面占大量画面容易单调——需要用**漂浮物（屋顶、路牌、汽车顶）**讲述“城市刚刚沉没”的故事，前几天能看到熟悉的城市地标从水下露出。
