# 《漂流日志》评测与上线改进记录

> 评测视角：按 IGN 式的游戏评测标准（玩法、呈现、上手、耐玩度、完成度）审查 v2 原型，列出问题、逐条修复，再按同一标准复评 v3。
> 分数是我自己的评估，不是真实媒体评分。

---

## 一、v2 评测：骨架很好，但还没做完

**评分：6.9 / 10**

### 一句话
《漂流日志》把 Survival Log 的"限时囤货 → 据点经营 → 死亡轮回"成功搬到了海上。"浮力即容量"和"城市逐区沉没"这两个点子立住了。但它更像一份非常好的垂直切片，而不是一款完整的游戏：没有声音、不能存档、没有新手引导，跑完一局后也没有多少理由再来一局。

### 亮点
- **核心张力成立。** 第一阶段钱、时间、负重三方互相挤压；"送货 vs 自己跑"、"先去低处抢货 vs 先回码头组装"都是真正的选择。
- **"浮力即容量"是最好的创意。** 囤得越多，木筏吃水越深。玩家的贪婪直接变成风险，不需要任何说明就能看懂。
- **美术统一、有氛围。** 一盏暖色马灯对着一整片黑海，夜里的荧光黑潮兽与暖光形成互补色，第一眼就有记忆点。
- **行动制时间让准备阶段从容。** 不再被真实倒计时追着跑，策略感更强。

### 问题（按上线优先级）

| 级别 | 问题 | 影响 |
|---|---|---|
| **P0** | **没有任何声音** | 生存游戏的一半氛围来自声音。海浪、雨声、怪物的低吼全都缺席，画面再好也显得"空"。 |
| **P0** | **不能存档 / 继续** | 一局要 20–40 分钟，关掉页面就全没了。这是上线的硬门槛。 |
| **P0** | **新手不知道该干什么** | 进入城市地图后没有任何引导。首次玩家不知道要先买原木、要回码头卸货、要组装设施；漂流阶段也不知道要造雨水收集器。 |
| **P0** | **没有暂停菜单 / 设置 / 玩法说明** | 无法调音量、无法查看操作、无法中途退出。 |
| **P1** | **设施信息不可读** | 净水机为什么不工作？蒸馏器现在产多少水？玩家只能猜。 |
| **P1** | **战斗单调** | 只有一种黑潮兽，每个大潮夜的体验都一样。 |
| **P1** | **只有一个胜利结局** | 设计文档提到的"灯塔守望者"没有实现，海图上的灯塔只是一次性的避难所。 |
| **P1** | **长期动力不足** | 没有成就，没有结算统计，死亡界面只有一行死因。 |
| **P1** | **叙事太薄** | 开场的旁白很好，之后就没有故事了。"漂流日志"这个名字没有落实成玩家能读到的日志。 |
| **P1** | **准备阶段没有意外** | 每一局的十小时都一样，打几局就成了固定路线。 |
| **P2** | **没有难度选择** | 生存新手和硬核玩家只能玩同一种难度。 |
| **P2** | **夜晚无事可做时只能干等** | 安全的夜里没有快进到天亮的办法。 |
| **P2** | **受击反馈弱** | 甲板被啃掉时只有一行文字，没有冲击感。 |
| **P2** | **小屏幕上 UI 互相遮挡** | 1280px 以下笔记本上面板会重叠。 |
| **P2** | **数值** | 雨水收集器太强，玩家很快囤到 100L 以上淡水，淡水这条线失去了张力。 |

## 二、v3 改了什么（逐条对应）

| 问题 | 修复 |
|---|---|
| 没有声音 | 新增 `audio.js`：用 WebAudio 实时生成声音，不需要任何音频文件。**环境音**：海浪随风浪起伏，雨声和风暴风声跟随天气变化。**音乐**：缓慢的氛围和弦，白天 / 夜晚 / 黑潮来袭三种情绪自动切换。**音效**约 20 种：结账、组装锤声、落水、鱼叉、怪物低吼、警报、雷声、钓到鱼、吃喝、成就等。 |
| 不能存档 | **自动存档**：准备阶段每个行动后存，漂流阶段每个游戏小时存，关闭页面时也会存。标题画面出现「继续上次 · 漂流第 N 天」。 |
| 不知道干什么 | 屏幕顶部新增 **「📌 下一步」目标提示**，根据当前状态动态给建议。例如："先去船厂买原木"、"背包快满了，回码头卸货"、"今晚是大潮夜，造防护栏"、"有生鱼，记得烹饪"。可以在设置里关掉。 |
| 没有菜单 | 左上角 ☰ 或 Esc 打开**暂停菜单**：继续、玩法说明、设置、成就、保存并返回标题。**设置**包括主音量、音乐、环境音、音效、目标提示、屏幕震动。 |
| 设施不可读 | 鼠标悬停任意设施或黑潮兽时显示**信息卡**：实时产出（如"正在接雨水 · 0.4L/小时"）、电力状态、耐久、生长进度。 |
| 战斗单调 | **三种黑潮兽**：蚀木者（常见）、跃鳗（第 3 天起出现，快而脆）、甲壳兽（第 5 天起出现，慢而硬）。三者外观和配色不同，分别是青、紫、橙。 |
| 只有一个结局 | 新增 **守灯人结局**：第 8 天以后抵达灯塔，用零件 ×3、蓄电池 ×2、玻璃 ×1 修好灯塔并留下来。现在有方舟、守灯人、死亡轮回三条结局。 |
| 长期动力不足 | 新增 **13 个成就**（如第一夜、潮退之后、老渔夫、鱼叉手、造船匠、船长、守灯人、困难难度抵达方舟）。死亡和通关时显示**结算统计**：天数、击退数、鱼、建造、船员、损失甲板、到访地点、难度。 |
| 叙事太薄 | 新增 **日记**：每天清晨按前一夜发生的事自动写一篇，写损失、收获、淡水、情绪和船员。还有**电台广播**：第 2/4/7/10/12 天断续收到"方舟号"的信号，把"活到第 12 天"变成一条有方向的故事线。 |
| 准备阶段没有意外 | 新增 **4 个随机事件**，每个都是"用时间换东西"的选择：帮慌张的店主搬货换罐头；花钱走后门躲开抢购的人群；邻居林姐请求同行，答应后开局就有一名厨师船员，但要分口粮；陪迷路的孩子找妈妈，换漂流开局士气加成。 |
| 没有难度选择 | 选身份时可选 **休闲 / 标准 / 困难**，影响黑潮兽数量与血量、风暴强度、身体消耗、起始现金。 |
| 夜里只能干等 | 安全的夜里出现 **「⏭ 跳到天亮」** 按钮，遇到黑潮兽或事件会自动停下。 |
| 受击反馈弱 | 甲板沉没时**屏幕震动 + 红色边缘闪烁 + 断裂声 + 落水声**。 |
| 小屏幕遮挡 | 1300px、1050px 和矮屏三档响应式缩放。 |
| 淡水过剩 | 雨水收集器产量下调到约 0.4L/小时，大约一台收集器养活一个人。救援船员因此真正构成"多一张嘴"的压力。 |
| 其他平衡 | 风暴伤害随难度缩放；守灯人结局门槛提高，避免它比方舟更容易达成。 |
| 物资不能指定使用 | 「物资」面板里可以点击指定食物食用、点击药品使用、一键喝水。 |

### 验证
- 9 局自动对局覆盖 3 种难度 × 3 种身份，包括事件、存档→读档往返、跳到天亮、三种结局。**没有出现任何运行时错误**。方舟、守灯人、沉没三种结局都能达成，成就能正常解锁。
- 用一个"会修船、会钓鱼、会刺怪"的自动玩家测试，休闲和标准难度一般能活 8–12 天，困难难度在 5–12 天之间。真人玩家的点击反应比自动玩家快得多，实际难度应该更低一些。

## 三、v3 复评

**评分：8.2 / 10**

### 一句话
现在它是一款完整的小型生存游戏：能存档，有声音，有引导，有三条结局和一整套成就，每一局的十小时和每一个夜晚都会有些不同。"浮力即容量"和"沉没的城市"两个核心创意仍然是最大的卖点。

### 仍然存在的局限（诚实说明）
- **2D 等距画面。** 原作是 3D 写实，本作是 Canvas 2D 程序化绘制，风格统一，但细节密度有上限。要做商业版，需要换引擎重做美术资源（见设计文档 2.10）。
- **内容量是"小品级"。** 17 种设施、3 种怪物、7 种海图节点、4 个准备事件、10 个漂流瓶，大概够 3–5 小时的游玩。
- **数值来自自动对局，没有真人数据。** 上线后最需要的是收集真人的死亡天数和死因分布，再微调。
- **只有简体中文。** 也没有手柄支持；触屏可以点按，但没有专门做适配。
- **存档在浏览器本地。** 清除浏览器数据会丢失存档。
