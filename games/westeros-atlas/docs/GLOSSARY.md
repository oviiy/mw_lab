# Bilingual glossary (EN ↔ 简体中文)

One rendering per term. Use the **中文** column in every content and data file. Unmarked terms follow the established
Chinese edition of the novels (重庆出版社, tr. 屈畅 et al.; also used by the 读客 reissue) as far as the reviewer could confirm.
Terms marked ◇ are the project's own rendering (no settled edition rendering could be verified) — correct them here
first, then in `src/data/*` and `src/content/*`. Common alternative renderings (TV subtitles, fan wikis) belong only in the
search `alt` lists in `src/data/*`, never in prose.

**Policy:** the review pass must make every content file use ONE rendering per term — the one in this table. Where it disagrees with an established Chinese-edition rendering the reviewer is confident about, prefer the established one and update this table.
