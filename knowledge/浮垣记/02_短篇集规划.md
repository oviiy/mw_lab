# 《浮垣记》短篇集规划

## 结构思路

- **十二个短篇，十二个视角**，每篇换一个种族、职业、地点或高度。读者像拼图一样，一块一块拼出整个世界。
- 全部发生在**升历 1137 年**这一年里，大致按时间排序：春天开云日 → 夏天守衡院暗流 → 秋天会合节 → 冬天第二座岛坠落。
- 每篇单独读都完整；连起来读能看到一条暗线：**褪光 → 下界有人 → 第二座岛坠落**。
- 十二篇已全部完成并经两次审稿修订。
- 时间顺序：春（1 坠石）→ 春末开云日（2 沉渊）→ 初夏（3 领航师、4 涡眼）→ 夏末（5 放风、6 压舱人）→ 秋（7 白衣、9 会合节；8 栖霞回到 1125 年）→ 深秋（10 听风台）→ 初冬（11 鲸歌）→ 冬（12 忆雨）。《压舱人》结尾那只系着马鬃的衡纹信鹭，是贺岚追到灰脊扑空后发出的。

**做法：**
- 熟套比喻换成这个世界里的东西：龙 → 搁浅的云鲸；蛇 → 困在瓶里的息萤；风箱 → 刚从根矿背了一筐矿石上来；看不见的巨手 → 删；胃悬到嗓子眼 → "像被谁从底下抽走了一块"；青筋暴起、平静得让人害怕、指节发白 → 删或改。
- "先画面、再解释"的句子只留画面：磐叔"石胎就是这样……"、"记不记得，它都在"、"知道和记得不一样，丫头"、刻画后的"是许多小小的、漂浮的岛"、"那光是从下面借来的"、砾结尾的"石胎什么都记得"。
- 世界集原句不再直接进正文（"风裔不问来处""远得像另一个世界"）。

- 第 4 篇"压……压……压"的三连只留高潮那一次；倒数计数（一寸、两寸；四个、五个）并进叙述；砾说"磐叔？"前补了"琥珀城只有一个石胎塔守"。

### 第七轮：把小说和世界连起来（读者导引）

作者反馈"有点看不明白，少了一些内容把小说和世界连起来"。正文的世界观是在故事里一点点露出来的，读者手里没有地图，也不知道各篇之间隔着多远。这一轮补的都是读者用的东西，不动故事本身：

- **[00_从这里开始读](00_从这里开始读.md)**：全书入口，包括阅读顺序、篇目表（在哪里、谁的眼睛、什么季节），以及作者资料的剧透提示。
- **[序章 · 给新驿员的第一页](短篇/00_序章.md)**：信鹭驿发给新驿员的小册子，用两分钟讲清天上、渊、涡眼、三环、苍息与遗忘、三种人和信鹭。结尾那封信，就是第 1 篇里送到第九百零七塔的那一封。
- **【途经】**：第 2–12 篇开头各加一小段。一只信鹭从上一篇的地方飞到这一篇的地方，交代方位、距离和当地的生计，把规划里"信鹭是镜头切换"的设想落到纸面上。第 8 篇用《天轨册》的"除名"带出十二年前，第 12 篇"鸟不飞了，往下"。
- **[上穹示意图](地图·上穹.svg)**：画出涡眼、各环、空带、荒带、九年线和散岛，并用篇号标出每篇故事的地点。
- **[13_读者手册](13_读者手册.md)**：不剧透，包括一页世界、三种人、术语表（注明首次出现的篇）、主要人物和公开年表。
