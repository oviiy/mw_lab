How to use this. Start with a desk and let it run from foundation to advanced — that first pass is the conceptual recap. Then run a mixed drill the day before the interview, because recall in a random order is the thing that actually gets tested. Read the insight even when you were right: about a third of these questions have a correct answer that is easy to reach for the wrong reason, and the insight is where that shows up.

Keyboard. 1–4 to answer, Space for the next question, F to flag. A–D, Enter and N work too. Picking an answer marks it straight away, so there is no undo — that is the trade for one keystroke instead of two.

What this is not. Multiple choice cannot test whether you can derive Itō’s lemma at a whiteboard, price a swap from first principles, or write clean code under pressure. It tests whether the facts are loaded. Treat a wrong answer as a pointer to something worth deriving on paper, not as a flashcard to memorise.
