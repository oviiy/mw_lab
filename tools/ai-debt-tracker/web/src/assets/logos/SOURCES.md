# Company logos

These logos are used only to identify the companies whose debt is analysed (nominative use). They are not a sign of endorsement or affiliation. All trademarks belong to their respective owners.

The files come from Wikimedia Commons, where they are marked public domain for copyright purposes. Trademark rights still apply. The only edits are:

* an XML header and comments were removed;
* the `viewBox` was cropped to the symbol for the three wordmark logos (Meta, Oracle, CoreWeave).

Colours and shapes are unchanged.

If a rights holder asks for a logo to be removed, delete the file and its entry in `IssuerMark.tsx`. That issuer will then show without a logo.
